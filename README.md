##Objective:
-To analyze real-world Google search data and identify trending topics, geographic interest, 
and keyword popularity using data visualization.

##Overview:
-This project uses Python and the Pytrends library to analyze Google search trends.
-It helps understand how search interest for different keywords changes over time and across countries.

##Tools & Libraries Used:
-Python
-Pandas
-NumPy
-Matplotlib
-Seaborn
-Plotly
-Pytrends

##Features:
-Country-wise search interest analysis
-📈 Trend analysis over time
-🗺️ Interactive world map visualization
-🔍 Keyword comparison (multiple topics)

##Visualizations:
-Bar chart for top countries
-Line chart for time-based trends
-Choropleth map for global interest

##Insights:
This project helps understand:
-Which countries are most interested in a topic
-How trends change over time
-Comparison between different keywords
